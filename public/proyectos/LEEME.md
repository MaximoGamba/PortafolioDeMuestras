# Capturas de los proyectos

Poné acá las imágenes de cada proyecto y referencialas en
`src/features/projects/projectsData.js`:

```js
image: '/proyectos/stock-y-ventas.png',
imageAlt: 'Panel de stock mostrando el listado de productos',
```

Recomendaciones:

- Proporción **16:9** (por ejemplo 1600×900) para que no se recorte.
- Formato **WebP** o PNG optimizado, idealmente por debajo de 300 KB.
- Si el sistema todavía no está terminado, sirve una captura con datos
  de prueba: es mucho más convincente que el marcador vacío.
- El texto de `imageAlt` lo leen los lectores de pantalla y aparece si la
  imagen no carga. Describí qué se ve, no repitas el nombre del proyecto.
